# Banking Transaction Data Analysis

## Project Overview

This project analyzes a synthetic banking transaction dataset using Python for basic data analytics and visualization.

The objective is to understand transaction patterns across transaction types, banking channels, account types, monthly trends, and transaction status.

## Dataset

The project uses a synthetic dataset named `bank_transactions.csv`.

The dataset contains 250 sample transactions with the following fields:

- Transaction_ID
- Date
- Account_ID
- Account_Type
- Transaction_Type
- Amount
- Channel
- Status

**Note:** The dataset is synthetic and created for educational/demo purposes. It contains no real customer or financial information.

## Objectives

- Understand and inspect banking transaction data.
- Clean and prepare the dataset for analysis.
- Analyze transaction types and transaction amounts.
- Compare banking channels.
- Analyze account types.
- Study monthly transaction trends.
- Examine transaction status.
- Present findings using visualizations.

## Methodology

1. Load the dataset using Pandas.
2. Inspect the data structure and basic statistics.
3. Check and handle data-quality issues.
4. Analyze transaction types, channels, and account types.
5. Analyze monthly transaction trends.
6. Examine transaction status.
7. Create charts using Matplotlib.
8. Summarize key observations.

## How to Run

1. Install Python 3.x.
2. Install the required libraries:
   `pip install -r requirements.txt`
3. Open `HimaniZade_BankingTransactionAnalysis.ipynb` in Jupyter Notebook or VS Code.
4. Keep `bank_transactions.csv` in the same folder.
5. Run the notebook cells from top to bottom.

## Key Information

The analysis is intended for learning and demonstration of a basic data analytics workflow. Results are based on the synthetic dataset and should not be interpreted as real banking statistics.
