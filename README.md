# Banking System – Python Mini Project

## Project Overview

This is a Python-based Banking System mini project that simulates basic banking operations through a simple menu-driven application.

## Features

- Create a new bank account
- Generate a unique account number
- Login using account number and PIN
- Check account balance
- Deposit money
- Withdraw money with balance checking
- Transfer money between accounts
- View transaction history
- Change PIN
- Logout
- Exit the banking system

## Technologies Used

- Python
- Random Module
- DateTime Module

## Python Concepts Used

- Variables and Data Types
- Conditional Statements
- Loops
- Functions
- Lists and Dictionaries
- Strings
- Modules
- Input and Output

## Project Structure

1. Create Account
2. Login
3. Account Menu
4. Check Balance
5. Deposit
6. Withdraw
7. Transfer
8. Transaction History
9. Change PIN
10. Logout

## How to Run

1. Download or clone this repository.
2. Open `Banking_system.py` in VS Code or any Python IDE.
3. Run the program.
4. Follow the instructions displayed in the terminal.
